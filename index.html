Unit 3

Relational Normalization Process (UNF → 1NF → 2NF → 3NF/BCNF)

1. First Normal Form (1NF)

Eliminated repeating groups. All attributes are atomic scalars.
Primary Key: (student_id, course_id)
Functional Dependencies:
• student_id → name, dept, year, email
• course_id → name, category, duration, capacity

2. Second Normal Form (2NF)

Removed partial functional dependencies on composite candidate key.
Decomposed into separate relations:
• STUDENTS(student_id [PK], name, dept, year, email)
• COURSES(course_id [PK], name, category, duration, capacity)
• ENROLLMENTS(enrollment_id [PK], student_id [FK], course_id [FK], status, score)

3. Third Normal Form (3NF / BCNF)

Removed transitive dependency in Courses (course_id → category_id → category_name).
Decomposed into:
• CATEGORIES(category_id [PK], category_name, description)
• COURSES(course_id [PK], name, category_id [FK], ...)
All relations are now fully in 3NF and BCNF!

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Unit 3: Ingest relational tables & wrangle
df_students = pd.DataFrame(students_data)
df_courses = pd.DataFrame(courses_data)
df_enrollments = pd.DataFrame(enrollments_data)

# Unit 4: Data Cleaning & Joins
df_merged = df_enrollments.merge(df_students, on='student_id').merge(df_courses, on='course_id')

# Unit 5: EDA & Visualizations
course_stats = df_merged.groupby(['course_id', 'course_name', 'capacity']).agg(
    total_enrolled=('enrollment_id', 'count'),
    completed=('status', lambda s: (s == 'COMPLETED').sum())
).reset_index()

plt.figure(figsize=(10, 5))
plt.bar(course_stats['course_name'], course_stats['total_enrolled'], color='#3b82f6')
plt.title('Course Popularity Analysis - Developer: Dhanush K (732925ITR017)')
